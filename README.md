# Make-up Class

ระบบจัดการเรียนชดเชยสำหรับสถาบันภาษา ดนตรี และกวดวิชา: แจ้งลา ตรวจสิทธิ์ จองรอบชดเชย และหักเครดิตเมื่อนักเรียนมาเรียนจริง

## ฟีเจอร์
- แจ้งลา และตรวจอัตโนมัติว่าแจ้งล่วงหน้าตามกฎหรือไม่
- ตรวจสิทธิ์ก่อนจอง: ใบลามีสิทธิ์/ยังไม่ถูกใช้, รอบอยู่ในอนาคตและในช่วงวันที่กำหนด, ไม่เกินครั้งต่อเดือน, เครดิตพอ
- จองรอบชดเชย / ยกเลิก (คืนสิทธิ์) / ไม่มา / มาเรียน (หักเครดิตใน transaction)
- ตั้งกฎต่อคอร์ส พร้อมกฎเริ่มต้น `*`
- จัดการนักเรียนและเติมเครดิต

## Tech Stack
PHP 8.3 (procedural + PDO), PostgreSQL (Supabase), Tailwind CSS (CDN), Docker (Apache), Render

## โครงสร้าง
```
├── index.php        # ทุกหน้า + การทำงาน (แจ้งลา, รอบชดเชย, เครดิต, กฎ)
├── config.php       # db(), h(), csrf(), rule(), can_book()
├── schema_pg.sql    # ตาราง + กฎเริ่มต้น
├── Dockerfile
├── .env.example
└── README.md
```

## ตารางข้อมูล
| ตาราง | เก็บอะไร |
|---|---|
| `students` | นักเรียน |
| `credits` | เครดิตคงเหลือต่อนักเรียน |
| `makeup_rules` | กฎต่อคอร์ส (`*` = ค่าเริ่มต้น) |
| `absences` | ใบลา, มีสิทธิ์หรือไม่, สถานะ (open / booked / done) |
| `makeup_bookings` | รอบชดเชย, สถานะ (booked / attended / no_show / cancelled), เครดิตที่หักจริง |

## กฎเริ่มต้น (`*`)
แจ้งล่วงหน้า 24 ชม. · ชดเชยได้ 2 ครั้ง/เดือน/คอร์ส · ต้องจองภายใน 30 วัน · หัก 1 เครดิต/ครั้ง

## Environment Variables
| ชื่อ | ความหมาย | จำเป็น |
|---|---|---|
| `DB_HOST`, `DB_PASS` | ข้อมูลเชื่อมต่อ PostgreSQL | ใช่ (หรือใช้ `DATABASE_URL`) |
| `DB_PORT`, `DB_NAME`, `DB_USER` | ค่าเริ่มต้น 5432 / postgres / postgres | ไม่ |
| `DATABASE_URL` | connection string สำรอง | ไม่ |
| `ADMIN_PASS` | รหัสผ่านเข้าระบบผู้ดูแล | ใช่ |

## ติดตั้ง
1. สร้างฐานข้อมูล แล้วรัน `schema_pg.sql` (เช่นที่ Supabase SQL Editor)
2. Push โค้ดขึ้น GitHub
3. Render → New → Web Service → เลือก repo → Runtime: Docker
4. ตั้ง Environment Variables ตามตารางด้านบน
5. Deploy แล้วเปิด URL เข้าสู่ระบบด้วย `ADMIN_PASS`

## ทดสอบบนเครื่อง
```bash
docker build -t makeup-class .
docker run -p 8080:80 --env-file .env makeup-class
# เปิด http://localhost:8080
```

## ข้อจำกัดปัจจุบัน
- ผู้ดูแลล็อกอินรหัสเดียว ยังไม่มีหน้าให้นักเรียนจองเอง
- ยังไม่เช็กที่นั่งเต็ม/ครูว่างของรอบชดเชย (ผู้ดูแลกรอกวัน/เวลาเอง)
- เครดิตนับรวมทุกคอร์ส ไม่หมดอายุ ไม่มีประวัติ ledger
- ชื่อคอร์สเป็นข้อความอิสระ ต้องสะกดตรงกับกฎ
